# 牛马瞧A

Windows 桌面上的轻量盯盘工具。使用 Python + PyQt6，在靠近任务栏的位置显示半透明、置顶的小窗口，查看指数点数、涨跌点数、沪深成交额及较上一交易日同刻的增减。

## 日常启动

1. 安装 Python 并勾选 **Add Python to PATH**。本项目已在 Python 3.14 + PyQt6 环境验证；其他 Python 版本需能安装兼容的 PyQt6。
2. 将完整项目放在可写目录，双击 **`start_silent.vbs`**。
3. 首次启动会检查 PyQt6，缺失时通过 `python -m pip install PyQt6` 安装，需要联网。正常启动不显示控制台窗口。

程序使用单实例锁，重复启动会提示已在运行。更新代码后，请先从系统托盘菜单选择「退出」，再双击 `start_silent.vbs`。

启动失败时，双击 `start_console.bat` 查看错误，也可检查 `logs/launcher.log` 和 `logs/app.log`。退出程序请使用托盘菜单。

开发时可以在项目根目录运行：

```powershell
python -m pip install PyQt6
python src/main.py
```

## 当前显示与操作

窗口保持两行布局：前 3 个指数和右侧涨跌家数在第一行，其余指数和成交额在第二行。成交额总值与比较值横向显示，内容变长时窗口会扩宽。

- 指数格式：`SH 3387.12 +7.82`，依次为简称、当前点数、涨跌点数；当前窗口不显示涨跌百分比。
- 成交额格式：`V:5822亿 -1318亿`，依次为沪深合计成交额、较上一交易日同刻的差额。
- 涨跌家数格式：`Z1234 D3456`，Z 为上涨家数，D 为下跌家数。统计沪深 A 股，不含北交所、B 股，平盘和停牌不计入；随行情刷新，悬停可查看统计时间。数据缺失或请求失败时显示 `--`，不影响指数和成交额显示。
- 正常行情状态显示 `OK`；行情请求失败显示 `ERR`。成交额数据不完整时，相应金额显示 `--`，可悬停查看原因。指数在请求失败时可能保留上次数据。

| 操作 | 效果 |
| --- | --- |
| 左键单击数据区域 | 立即刷新指数行情和实时成交额；同刻差额仍按独立定时器刷新 |
| 左键拖拽 | 移动窗口，松开后保存位置 |
| 右键单击数据区域 | 打开设置 |
| 悬停成交额区域 | 查看行情时间、比较日期和分钟、双方金额及差额（保留两位小数，单位亿元） |
| 右键单击托盘图标 | 显示窗口、打开设置或退出 |
| 双击托盘图标 | 显示窗口 |

### 设置

- 行情刷新间隔：5～300 秒，默认 10 秒。
- 成交额对比间隔：1 / 5 / 15 / 30 分钟，默认 1 分钟。
- 显示指数：在下表范围内勾选，修改刷新间隔时保留已有指数顺序。
- 老板键：界面提供反引号、F12、Ctrl + 反引号、Esc、禁用等选项。目前实现为窗口快捷键，受焦点限制，不能保证在其他应用中隐藏或恢复窗口；修改后需重启程序重新绑定。

行情间隔、对比间隔和指数选择保存后立即应用。位置和设置保存在本机 `config/settings.json`，缺失时使用代码内置默认值。

| 指数 | 窗口简称 | 行情代码 | 默认显示 |
| --- | --- | --- | --- |
| 上证指数 | SH | sh000001 | 是 |
| 深证成指 | SZ | sz399001 | 是 |
| 创业板指 | CY | sz399006 | 是 |
| 沪深300 | IF | sh000300 | 是 |
| 上证50 | IH | sh000016 | 是 |
| 中证1000 | IM | sh000852 | 是 |
| 科创50 | KC | sh000688 | 否 |
| 中证500 | ZZ | sh000905 | 否 |
| 中小板指（界面名称） | ZX | sz399005 | 否 |

设置面板中的 HS、SZ50、ZZ1000 分别对应窗口里的 IF、IH、IM，展示的是指数行情。

## 成交额与较昨同刻

实时成交额按行情刷新间隔更新；差额按独立的对比间隔更新，两者的截至时间可能不同，以悬浮说明为准。

```text
差额 = 本交易日截至某分钟的累计成交额
     − 上一交易日截至同一分钟的累计成交额
```

正数表示放量，负数表示缩量，窗口显示值四舍五入到整数亿元。金额来自接口中的累计成交额字段，不用成交量估算。

- **统计范围**：腾讯上证、深证行情的成交额合计，不含北交所；不再叠加创业板等子指数。勾选哪些指数不会改变成交额口径，与其他软件的全市场口径可能不同。
- **历史数据**：启动时获取腾讯最近五个交易日的分时数据，不要求上一交易日开过本工具。之后优先获取当日分时，跨日重新取得比较基准。
- **时间对齐**：取沪深两市共有的最新已完成分钟；正在变化的下一分钟数据不参与比较。上一交易日根据接口实际交易日期确定，不按自然日减一天。
- **休市处理**：午休使用上午最后可用分钟；收盘后使用收盘分钟。非交易日以接口返回的实际交易日期为准。
- **数据缺失**：两市日期不一致、缺少同一分钟、盘中当日分时数据超过三分钟未更新等情况，差额显示 `--`。若只有比较数据不可用，实时成交额仍可独立显示；恢复后自动更新。

### 数据来源与限制

行情使用腾讯和东方财富网页行情公开接口，无需账号或付费订阅：

- 指数及实时成交额：`https://qt.gtimg.cn/`
- 近五日分时：`https://web.ifzq.gtimg.cn/appstock/app/day/query`
- 当日分时：`https://web.ifzq.gtimg.cn/appstock/app/minute/query`
- 涨跌家数：`https://push2.eastmoney.com/api/qt/ulist.np/get`，合计上证 A 股指数与深证 A 指返回的上涨、下跌家数，不叠加创业板等子指数。

需要网络连接。公开接口的格式、可用性和返回数据可能变化；工具按轮询方式更新，不提供逐笔推送或服务可用性保证。

## 本地存储与磁盘占用

| 文件 | 内容及保留规则 |
| --- | --- |
| `config/settings.json` | 本机设置和窗口位置，每次覆盖保存 |
| `config/minute_cache.json` | 按交易日存储沪深分钟累计成交额，单位为元；每次保存仅保留最新 5 个交易日，淘汰更早数据 |
| `config/minute_cache.json.legacy-*.bak` | 旧版或损坏缓存成功重建前的备份；正常使用新版缓存不会每天生成，确认恢复正常后可自行删除 |
| `logs/launcher.log`、`logs/launcher.log.1` | 启动及子进程输出，每份最多 512 KiB，仅保留当前文件和一份备份，合计最多 1 MiB |
| `logs/launcher.log.lock` | 启动日志写入锁，约 1 字节 |
| `logs/app.log`、`.1`、`.2` | 运行日志，约 1 MB 轮转，保留两份备份，合计约 3 MB |

启动日志会在写入时裁剪旧版遗留的超大日志。正常缓存和日志不会随使用天数持续累积。缓存写入使用临时文件并原子替换；缓存无法落盘时，本次仍可使用在线数据计算。

旧版本可能留下 `config/prev_volume.json`，当前程序不再使用。单实例锁位于用户主目录下的 `.system-monitor/instance.lock`。

运行配置、缓存、迁移备份、日志、Python 字节码和测试临时文件均不纳入版本控制；更新本项目时保留本机配置。

## 开机自启（可选）

1. 按 `Win + R`，输入 `shell:startup`。
2. 在打开的目录中创建指向本项目 `start_silent.vbs` 的快捷方式。
3. 保留项目文件在原目录；移动项目后需更新快捷方式。

## 项目结构

```text
system-monitor-prototype/
├── src/
│   ├── main.py                 # Qt 窗口、设置、行情、托盘和单实例检查
│   ├── turnover.py             # 分时成交额、同刻对比和五日缓存
│   ├── breadth.py              # 沪深 A 股涨跌家数与行情时间
│   └── launch_silent.py        # 静默启动、依赖检查和启动日志轮转
├── tests/                      # 成交额、Qt 界面和启动链路测试
├── config/                     # 本机配置和缓存，运行时按需生成
├── logs/                       # 本机日志，启动时生成
├── start_silent.vbs             # 日常双击入口
├── start_silent_inner.bat       # 定位 Python，调用静默启动器
├── start_console.bat            # 带控制台的诊断入口
├── prototype.html              # 静态视觉原型，包含未接入桌面程序的演示效果
├── test_fetch.py                # 旧版联网排查脚本，不属于自动测试
└── README.md
```

桌面程序是独立浮动窗口，未嵌入 Windows 任务栏。网页原型中的涨跌幅百分比和完整指数悬浮面板不代表桌面程序已支持。

## 开发验证

在 Windows 上安装 PyQt6 后，于项目根目录运行：

```powershell
python -B -m unittest discover -s tests -v
```

自动测试使用模拟行情和隔离的临时配置，不修改个人设置、不请求行情接口。启动测试会在含中文和空格的临时目录中执行真实 VBS → BAT → Python 启动链，使用短时测试程序替代桌面窗口，并验证大量输出下的日志大小限制。

`test_fetch.py` 是单独的旧版联网诊断脚本，包含关闭 TLS 证书校验的探测逻辑；正式程序使用 HTTPS 默认校验，不依赖此脚本。
