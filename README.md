# 牛马瞧A

打工人的任务栏盯盘小工具。

上班想偷偷看两眼大盘，又不想被发现？牛马瞧A 藏在任务栏里，毫不起眼，老板键一键隐藏，专为牛马设计。

## 目录结构
```
system-monitor-prototype/
├── src/
│   └── main.py              # 主程序
├── config/
│   └── settings.json        # 配置文件（运行时生成）
├── prototype.html           # 视觉原型
├── start_console.bat        # 方式一：带控制台启动（调试）
├── start_silent.bat         # 方式二：静默启动（日常使用）
└── README.md               # 本文件
```

## 使用方式

### 方式一：控制台模式（开发调试）
双击 `start_console.bat`
- 会显示黑色命令行窗口
- 可以看到程序运行日志
- 按 `Ctrl+C` 可停止程序
- 适合排查问题

### 方式二：静默模式（日常使用）
双击 `start_silent.bat`
- 无命令行窗口，后台运行
- 只在任务栏显示数据
- 适合日常隐蔽使用

### 命令行方式
```bash
# 先安装依赖（只需一次）
pip install PyQt6

# 运行程序
cd E:\hermes_space\system-monitor-prototype
python src\main.py
```

## 操作说明

| 操作 | 功能 |
|------|------|
| 按 `` ` `` 键 | 老板键：隐藏/显示 |
| 左键点击数据 | 立即刷新 |
| 右键点击数据 | 打开设置面板 |
| 托盘图标右键 | 显示/设置/退出 |

## 设置面板
右键点击任务栏上的数据区域，可以：
- 调整刷新间隔（5秒~5分钟）
- 切换老板键（` ~ / F12 / Ctrl+` / Esc / 禁用）
- 选择显示哪些指数（SH/SZ/CY/KC/HS/ZZ等）

## 数据说明
- 数据来源：腾讯行情公开API
- 刷新间隔：默认10秒
- 显示格式：`代码 当前点数 涨跌点数 涨跌幅%`
- 示例：`SH 3387.12 +7.82 +0.23%`

## 低调特性
- 无色彩：全部灰度显示，涨跌用 +/- 区分
- 无中文：两字母代码（SH/SZ/CY等）
- 位置：任务栏中间偏右，像系统组件
- 字体：Segoe UI Variable（Win11原生字体）
- 视觉：和任务栏一致的半透明背景

## 开机自启（可选）
1. 按 `Win + R`，输入 `shell:startup`
2. 把 `start_silent.bat` 复制进去，或创建快捷方式
3. 开机自动静默启动

## 注意事项
- 需要 Windows 10/11 系统
- 需要安装 Python 3.8+ 和 PyQt6
- 需要网络连接获取实时数据
- 仅在工作日交易时段有实时数据更新
